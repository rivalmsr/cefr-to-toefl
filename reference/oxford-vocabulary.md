# Oxford Vocabulary Pool (Oxford 3000/5000, CEFR-tagged)

A graded vocabulary pool based on the **Oxford 3000** (≈A1–B2) and **Oxford 5000** (≈B2–C1),
the primary source for `/quiz` vocabulary questions and `/toefl` vocab items. Aligned with
the user's Anki deck (Oxford 3000, tier A1 in progress). **Filled in gradually** per unit — do
not assume tier A1 is complete.

> Columns: **Word · POS · CEFR · Meaning · Arti · Example** (Meaning = definisi English sederhana, Arti = terjemahan Indonesia). The CEFR tag = the official Oxford tier.
> When writing a unit, add that unit's themed word batch to the matching level table.
> **Cek level di PDF resmi** `reference/sources/oxford-3000-by-cefr.pdf` / `oxford-5000-by-cefr.pdf`
> (lihat `reference/official-sources.md`). Kata yang tidak ada di Oxford 3000/5000 → tabel
> **Di luar Oxford** di bawah (CEFR = `—`).
