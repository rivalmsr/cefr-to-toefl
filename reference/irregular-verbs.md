# Irregular Verbs — V1 · V2 · V3 (Oxford 3000, A1–A2)

Sumber kata untuk skill **`/quiz-v`**. Dikelompokkan per **pola bunyi** (bukan abjad), karena
pola membantu mengingat: kalau tahu *drink–drank–drunk*, *sing–sang–sung* jadi lebih mudah.

- **Level CEFR** = dicek ke `reference/sources/oxford-3000-by-cefr.pdf` (2026-11-02): 64 kata
  kerja tidak beraturan di **A1**, 21 di **A2**. Kata kerja di atas A2 belum masuk.
- **Bentuk V2/V3** = bentuk standar (British English). Kalau ada dua bentuk yang sah, keduanya
  ditulis dan **keduanya diterima** saat dinilai.
- **V2** = past simple (*kemarin aku…*, Unit 2, Point 2). **V3** = past participle, dipakai
  setelah *have/has* (Unit 1, Point 2).
- `/quiz-v` hanya menguji **hafalan bentuk**: diberi V1 + arti → ketik V2, V3 (tanpa soal
  kalimat). Pemakaian V2 di dalam kalimat (sejak 2026-11-08 ada di Unit 2) dilatih di `/quiz` ·
  `/quiz-t`.

## Prioritas (dari kesalahan nyata di quiz)
| Kata | Kesalahan | Sumber |
|---|---|---|
| `wear` | *~~weared~~* → **worn** | `/quiz-t` 2026-11-02 |
| `have` | *~~I have this coat for 3 years~~* → **have had** | `/quiz-t` 2026-10-29 |
| `know` | *~~How long do you known~~* → **have** you known (bentuk V3-nya sudah benar) | `/quiz` 2026-11-01 |

## P5 — Khusus (hafalkan satu per satu)
| Verb | Arti | V2 | V3 | CEFR |
|---|---|---|---|---|
| be | adalah, berada | was / were | been | A1 |
| do | melakukan | did | done | A1 |
| go | pergi | went | gone | A1 |
| lie | berbaring | lay | lain | A1 |

> *be*: **was** untuk I/he/she/it, **were** untuk you/we/they. Dinilai benar kalau kamu menulis
> keduanya (*was/were*).
> *lie* (berbaring) ≠ *lie* (berbohong, B1, beraturan: *lied · lied*). Di `/quiz-v` selalu
> diberi arti "berbaring".
