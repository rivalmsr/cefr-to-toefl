# Quiz Evaluation — Weakness Tracker (/quiz)

Updated automatically by the `/quiz` skill after each session. Tracks accuracy **per
grammar/skill tag**, **per error type**, and **per unit**, then ranks the **weak areas**.

**Status thresholds:** accuracy <60% 🔴 WEAK · 60–79% 🟡 · ≥80% 🟢
(needs at least **3 attempts** before a status is computed; below that = ⚪ not enough data)

**Grammar tags are tracked in two lanes** (since 2026-11-02): **MCQ** = recognition (`/quiz`
multiple choice, `/diagnostic`) and **Prod** = production (`/quiz-t`, `/quiz writing`). Each lane
gets its own status. **Tag status** = 🟢 only if **both** lanes are 🟢; otherwise the worst lane
with ≥3 attempts (🔴 > 🟡); one lane 🟢 + other lane ⚪ → 🟡 (not proven yet in that lane); both
lanes < 3 → ⚪. Skill/error/unit tables stay single-lane, all-time.

**Lane status = last 10 attempts** (since 2026-11-02): each lane keeps a sequence (oldest → newest,
`✓`/`✗`, max 10; append in question order, drop from the left). Lane % = ✓ in the window ÷ window
size (fewer than 10 attempts → all of them; < 3 → ⚪). `All-time` C/T is kept for info only.
_Sequences before 2026-11-02 were rebuilt from `history.md`; where the order inside a session was
unknown, the miss was placed as the older item (conservative)._
