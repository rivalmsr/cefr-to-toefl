# Verb Forms Evaluation — Tracker (/quiz-v)

Updated automatically by the `/quiz-v` skill after each session. Tracks recall of irregular verb
forms (V2 · V3) **per verb** and **per pattern** (`reference/irregular-verbs.md`). Separate from
`evaluation.md`: `/quiz-v` never writes there, and `/quiz`·`/quiz-t` never write here.

**Status thresholds:** accuracy <60% 🔴 · 60–79% 🟡 · ≥80% 🟢 (fewer than **3 attempts** = ⚪).

**Per verb = last 5 attempts:** each verb keeps a sequence (oldest → newest, `✓`/`✗`, max 5; drop
from the left). Status = ✓ in the window ÷ window size. A verb is added the first time it is tested.
**Per pattern** = all-time Correct/Total (single lane).

An attempt is ✓ only if **both forms** are right (the item shows V1 + meaning; the user types V2
**and** V3), spelling included. Capital letters ignored. Both forms accepted where the
reference lists two (*learned/learnt*). Hint (💡) used or skipped (⏭️) → ✗.
